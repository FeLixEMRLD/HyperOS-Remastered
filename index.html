ROM Engineering & Capabilities

Enhanced Visuals

Advanced Textures
Implemented a system-wide "Gaussian" blur to UI elements.
Note: The system may experience slight lag when handling advanced textures; utilize this feature wisely for optimal performance.
Elevated Lockscreen Styles
Added new "People" and "Animals" lockscreen designs to enhance the user experience.
High-End Animations
Integrated premium system animations, including wallpaper zoom for both the native launcher and the Always-On Display (AOD), providing extensive home screen customization options.

Overall Features

System Integrity & Flexibility
Upgraded system integrity to "Strong" and integrated Kaorios to maximize operational flexibility.
Disabled Signature Verification
Removed system-wide signature verification, enabling the unrestricted installation of modified system applications.
Disabled Secure Flag
Bypassed the secure flag constraint, allowing users to take screenshots within any application.
Camera Enhancements
Added the "Live Photo" feature directly inside the native camera application.
Dynamic Refresh Rates
Implemented a 90Hz screen refresh rate option, giving users the flexibility to switch seamlessly between 120Hz, 90Hz, and 60Hz.
